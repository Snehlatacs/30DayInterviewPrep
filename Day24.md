## 🧠 DSA – Circular Linked List (CLL)
### 📚 Learn:
* Last node points to the head (tail.next = head)

* Use-cases: OS round-robin, media playlists

* Benefits: memory reuse, looped traversal

### 🧪 Practice:
* Implement a CircularLinkedList class in JavaScript

* Insert elements in a circle

* Traverse from any node back to starting point

* Detect circular loops (cycle detection with Floyd’s)

### 💡 Bonus:
* Convert a normal singly list to circular

* Practice 1 circular loop detection from LeetCode
